## Per-rule methodology

For each rule (brief Section 6.3): what it covers, what it explicitly does *not*
cover, the data source it needs, and a note on false-positive expectations
(home-lab FP rates are **not** representative of enterprise noise).

### T1110.001 — RDP brute force
Covers a burst of ≥8 failed RDP logons (Event ID 4625, LogonType 10) grouped by
source IP. **Does not cover** the failed→success *sequence* correlation or
password spraying across many accounts from rotating IPs — sequence/stateful
correlation belongs to the SIEM correlation layer (roadmap). **Data source:**
Windows Security 4625. **FP note:** in a home lab, near-zero; in an enterprise,
NAT egress IPs and health-check tooling create real noise — tune the threshold.

### T1059.001 — Suspicious PowerShell
Covers PowerShell process creation with encoded commands, bypass+hidden combos,
or download-cradle strings. **Does not cover** obfuscation that avoids all these
tokens (e.g. concatenated strings, AMSI bypass without cradle keywords). **Data
source:** Sysmon Event ID 1 / Security 4688 (process_creation). **FP note:**
legitimate deployment tooling uses encoded commands; expect meaningful
enterprise FPs, low home-lab FPs.

### T1003.001 — LSASS credential dumping
Covers Sysmon ProcessAccess (Event ID 10) into lsass with high-access masks, and
known dumping tool command lines. **Does not cover** stealthy handle-duplication
or driver-based dumping. **Data source:** Sysmon 10 + process_creation. **FP
note:** EDR/AV and crash-dump tooling legitimately read LSASS — an enterprise
must allow-list them; a home lab rarely sees this.

### T1547.001 — Registry Run key persistence
Covers value-set (Event ID 13) under Run/RunOnce keys. **Does not cover** other
autostart locations (services, WMI, startup folder). **Data source:** Sysmon 13.
**FP note:** installers write Run keys legitimately; moderate enterprise FPs.

### T1021.002 — SMB admin-share lateral movement
Covers command lines touching ADMIN$/C$/IPC$ combined with net/copy/psexec.
**Does not cover** SMB movement that doesn't shell out (pure API/WMI). **Data
source:** process_creation (and optionally 4624 LogonType 3). **FP note:** admins
and software-distribution tools use admin shares — real enterprise FPs.

### T1053.005 — Scheduled task creation
Covers schtasks/at `/create`. **Does not cover** task creation via COM/PowerShell
`Register-ScheduledTask` (a documented gap → roadmap). **Data source:**
process_creation. **FP note:** software updaters create tasks constantly — high
enterprise FP, hence `level: medium`.

### T1070.001 — Event log clearing
Covers the audit event (1102/104) and CLI tooling (wevtutil cl / Clear-EventLog).
**Does not cover** selective record deletion or log-service tampering. **Data
source:** Security 1102 + process_creation. **FP note:** near-zero legitimately;
any hit warrants review.

### T1078 — Valid account misuse
Covers interactive/remote logon by built-in or service accounts on a watchlist.
**Does not cover** impossible-travel or off-hours anomaly detection, which need
geo-IP + per-user baselines (stateful → roadmap). **Data source:** Security 4624.
**FP note:** break-glass procedures; tune the watchlist per environment.

### T1071.001 — Suspicious web user-agent (C2)
Covers requests with scripting/tooling user-agents. **Does not cover** true
beaconing (timing/jitter analysis) or domain-fronted/legit-UA C2. **Data
source:** proxy/Zeek http.log or Sysmon 22/3 enriched with UA. **FP note:**
automation and package managers use these UAs — meaningful enterprise FP.

### T1136.001 — Local account creation
Covers Security 4720 and net-user-add / New-LocalUser. **Does not cover** domain
account creation (T1136.002). **Data source:** Security 4720 + process_creation.
**FP note:** IT provisioning is legitimate; moderate FP.

### T1486 — Ransomware file impact
Aggregation: ≥15 file writes (Event ID 11) with ransom extensions per host.
**Does not cover** in-place encryption that keeps original extensions, or
ransomware using random extensions. **Data source:** Sysmon 11. **FP note:**
near-zero legitimately; the threshold guards against a stray `.enc` file.

### T1018 — Remote system discovery
Covers net view / arp -a / nltest enumeration. **Does not cover** PowerShell/WMI
or LDAP-based discovery. **Data source:** process_creation. **FP note:** admins
and logon scripts run these — high FP, hence `level: low`.

### T1055 — Process injection
Covers CreateRemoteThread (Event ID 8) into a LOLBin watchlist. **Does not
cover** other injection styles (APC queue, process hollowing, mapped sections).
**Data source:** Sysmon 8. **FP note:** some EDR/debuggers/accessibility tools
inject legitimately — allow-list them in an enterprise.
